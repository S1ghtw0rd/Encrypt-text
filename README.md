# Encrypt-text

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Python](https://img.shields.io/badge/Python-3.x-blue.svg)

Консольная программа на Python для шифрования и расшифровки текста шифрами **Цезаря** и **Атбаш**. Работает с русским и английским языками.

Это мой первый проект на GitHub.

## Возможности

- Шифрование и расшифровка текста шифром Цезаря
- Шифрование и расшифровка текста шифром Атбаш
- Поддержка русского и английского алфавитов
- Простое интерактивное меню в командной строке
- Без сторонних зависимостей, нужен только Python

## О шифрах

**Шифр Цезаря** сдвигает каждую букву алфавита на заданное число позиций.
Для работы нужно знать величину сдвига:

- **положительное число**: сдвиг вправо, например `3`
- **отрицательное число**: сдвиг влево, например `-3`

Пример: при сдвиге `3` слово `hello` превращается в `khoor`.

**Шифр Атбаш** заменяет каждую букву на зеркальную ей в алфавите (первая на последнюю, вторая на предпоследнюю и т. д.). Ключ не нужен, а шифрование и расшифровка выполняются одной и той же операцией.

Пример: `hello` превращается в `svool`.

## Установка

Требуется [Python 3](https://www.python.org/downloads/).

**Вариант 1. Клонировать репозиторий:**

```bash
git clone https://github.com/S1ghtw0rd/Encrypt-text.git
cd Encrypt-text
```

**Вариант 2. Скачать ZIP-архив:**

1. На странице репозитория нажмите **Code → Download ZIP**
2. Распакуйте архив
3. Откройте командную строку в папке с проектом

## Запуск

```bash
python main.py
```

На некоторых системах (Linux, macOS) команда может называться `python3`:

```bash
python3 main.py
```

## Как пользоваться

1. Выберите язык: русский или English.
2. Введите текст. Лучше без цифр и знаков препинания.
3. Выберите шифр: Цезаря или Атбаш.
4. Для шифра Цезаря укажите сдвиг (положительное число для сдвига вправо, отрицательное для сдвига влево).
5. Получите результат.

> Если расшифровка получилась неверной, попробуйте другой шифр или другой сдвиг.
